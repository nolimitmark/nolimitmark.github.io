// Selected Work

ELMS

Education Platform // Built from scratch

React TypeScript FastAPI PostgreSQL AWS

ELMS is an education platform I built from scratch for lecturers and students. I handled the architecture, frontend, backend, database, infrastructure, and the custom systems that power the platform.

Rather than relying entirely on existing third-party tools, I built several core parts of the experience myself, including the live classroom system, real-time whiteboard, and structured document editor.

Live Classroom

real-time system

I built the live meeting experience used for remote lectures and integrated the custom whiteboard directly into the classroom. The system handles real-time communication between lecturers and students while keeping the classroom state synchronized.

Live classroom preview

Canvas Whiteboard Engine

React TypeScript Fabric.js

A custom canvas-based whiteboard built specifically for educational environments. It supports drawing, object manipulation, real-time synchronization and state persistence.

One of the problems I had to solve was preserving the whiteboard state when users refreshed or reconnected. I introduced a state layer that could restore the latest state before continuing the real-time update flow.
